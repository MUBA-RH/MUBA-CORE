# MUBA-CORE

Architecture and documentation boundary for MUBA identity, configuration, policy, and continuity. The active production runtime stays in [MUBA](https://github.com/MUBA-RH/MUBA); this repository is not a separately deployed application.

See [MODULE_MAP.md](MODULE_MAP.md) for ownership and [LIFECYCLE.md](LIFECYCLE.md) for the change process. No tokens, secrets, environment values, or production code are copied here.
